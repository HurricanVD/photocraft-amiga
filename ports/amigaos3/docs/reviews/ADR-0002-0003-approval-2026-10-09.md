## Decisions reviewed

1. **ADR-0002 — accepted.** PhotoCraft Rust is the semantic oracle. Preserve 256x256 sparse COW tile and format-native encoded values, negative coordinate semantics, masks/layers/groups in the *eventual* engine and bounded memory on m68k. Existing typed C99 `PcRaster` is an experiment, not a stable C ABI or complete `Document` implementation.
2. **ADR-0003 — accepted.** Establish test/compatibility profiles (host, GCC13.3/vamos, GCC16 evaluation and MiniGL/WinUAE manual lane), strict compiler provenance, no mixed runtime objects, and real m68k/ABI/runtime evidence. **Do not infer a production compiler selection**: GCC13 remains opt-in for tests, and the vxplatform GCC16 default does not automatically become PhotoCraft's production default.
